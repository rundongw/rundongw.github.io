This is the first post on the blog section of this site — mostly here to
confirm the plumbing works. Future posts can be research notes, conference
recaps, or anything else worth writing down.

To add a new post, create a new Markdown file under `content/blog/` (you can
run `hugo new blog/my-post-title.md` from the project root) and set
`draft: false` when it's ready to publish.
